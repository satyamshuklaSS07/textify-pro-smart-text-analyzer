# Textify Pro — Smart Text Analyzer

A colorful, animated, 3D-style real-time text analytics project for the VEDA Technology internship task.

## Features
- Live character count
- Character count without spaces
- Word and sentence count
- Paragraph and line count
- Average word length
- Estimated reading time
- 10,000-character progress bar
- Copy, clear and sample actions
- Dark/light theme
- Responsive UI
- 3D-style cards, gradients, glow effects and animated background
- Vanilla HTML, CSS and JavaScript

## Tech
HTML5 • CSS3 • JavaScript

## Run
Open `index.html` in any modern browser.

## Internship mapping
Uses textarea input events, JavaScript string methods, trimming, whitespace splitting and live DOM updates.
