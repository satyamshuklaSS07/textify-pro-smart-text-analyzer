# Textify Pro — Smart Text Analyzer ✨

Textify Pro is a modern, responsive and real-time text analysis web application built with HTML5, CSS3 and JavaScript. It helps users instantly analyze their text with useful writing statistics through a colorful 3D-style interface.

## 🚀 Live Demo

https://textify-pro-smart-text-analyzer-o4g.vercel.app/

## 📂 GitHub Repository

https://github.com/satyamshuklaSS07/textify-pro-smart-text-analyzer

## ✨ Features

- Real-time character count
- Character count without spaces
- Word count
- Sentence count
- Paragraph count
- Line count
- Average word length
- Estimated reading time
- 10,000-character limit
- Live character progress bar
- Copy text functionality
- Clear text functionality
- Sample text generator
- Dark / Light mode
- Responsive design
- Colorful gradient UI
- Glassmorphism effects
- 3D-style cards and depth effects
- Animated background elements

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Vercel
- GitHub

## ⚙️ How It Works

1. Enter or paste text into the editor.
2. JavaScript listens for text input in real time.
3. The application calculates characters, words, sentences, paragraphs and lines.
4. Additional writing insights are calculated automatically.
5. The dashboard updates instantly without reloading the page.
